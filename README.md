## Обучение Faster R-CNN
В начале работы я подумал, что хорошей идеей будет встроить предобученные под какой-нибудь домен веса.
В директории test представлен протокол интеграции предобученных медицинских весов **RadImageNet** в бэкбон **ResNet50** для архитектуры Faster R-CNN.

- Длительное время обучения (~8 часов на 20 эпох). Дальнейшая разработка прекращена в пользу более легковесных YOLO-детекторов.
- Модель демонстрировала правильный тренд — постепенный рост $mAP$ и падение функции потерь ($loss$).
